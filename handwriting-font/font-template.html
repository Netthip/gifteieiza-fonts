เขียนตามช่องในหน้า 2–10 แล้วสแกนส่งกลับมา เดี๋ยวแปลงเป็นไฟล์ฟอนต์ (.ttf) ให้ใช้ได้เลย
หัวใจสำคัญ — เรื่องวรรณยุกต์ที่กิฟกังวล: ในแม่แบบนี้ วรรณยุกต์ ( ่ ้ ๊ ๋ ) และการันต์ ( ์ ) มีให้เขียน 2 ชุด
① ชุด "ปกติ" — ใช้ตอนอยู่บนพยัญชนะตรงๆ เช่น ก่ ป้า ฟ้า → เขียนในแถบสระบน
② ชุด "สูง" — ใช้ตอนมีสระบนคั่นอยู่ เช่น กิ๊ฟ ที่ เสื้อ → เขียนในแถบบนสุด
พอทำเป็นฟอนต์ ระบบจะเลือกตัวที่ถูกให้อัตโนมัติ คำว่า กิ๊ฟ สระอิกับไม้ตรีจะไม่ทับกันแน่นอน

ผังชั้นการเขียน
ทุกช่องเขียนจะมีเส้นบรรทัดแบบนี้
— เส้นทึบหนา = เส้นฐาน (บรรทัดล่างของตัวอักษร)
— เส้นทึบบาง = ความสูงหัวตัวอักษร
— เส้นประ = เพดานชั้นวรรณยุกต์

แถบสีเหลืองในช่อง = ตำแหน่งที่ต้องเขียน
เครื่องหมายตัวนั้น อย่าเขียนออกนอกแถบ
วิธีใช้
  1. ปริ้นทุกหน้าลงกระดาษ A4 ขาว ที่ ขนาดจริง 100% (ห้ามย่อ–ขยายให้พอดีหน้า)
  2. ใช้ปากกาหมึกดำเส้นคม 0.5–0.7 มม. (เจลหรือหมึกซึม) — ห้ามดินสอ / ปากกาน้ำเงิน
  3. เขียนให้เต็มกรอบเส้นประสีส้มพอดี — ห้ามอ้วนกว่ากรอบ ห้ามสูงกว่ากรอบ ทุกตัวจะได้ขนาดเท่ากันหมด (ตัวสีเทาคือตัวอย่างตำแหน่ง ส่วนรูปทรงเขียนตามลายมือกิฟเอง)
  4. ข้อยกเว้นที่ยื่นออกนอกกรอบได้ : หางบนของ ป ฝ ฟ ฬ ยื่นขึ้น · หางล่างของ ฎ ฏ ยื่นลง · ตัว โ ใ ไ สูงกว่ากรอบได้
  5. ช่องที่มีแถบเหลือง (สระบน สระล่าง วรรณยุกต์) เขียนเฉพาะเครื่องหมายนั้นตัวเดียว เล็กๆ ให้พอดีกรอบประในแถบเหลือง
  6. เขียนพลาดไม่ต้องขูดลบ — ใช้ช่อง "สำรอง" ท้ายหมวด หรือปริ้นหน้านั้นซ้ำแล้วเขียนใหม่
  7. อย่าเขียนโดนสี่เหลี่ยมดำมุมกระดาษ (ใช้จัดแนวตอนสแกน)
  8. เสร็จแล้วสแกน 300–600 dpi (ขาวดำหรือ grayscale) หรือถ่ายรูปตรงๆ แสงสม่ำเสมอ ไม่เอียง แล้วส่งไฟล์มาได้เลย
ซ้อมมือก่อนเริ่ม — ลองเขียนคำเหล่านี้เพื่อเช็กว่าวรรณยุกต์ไม่ชนสระ :  กิ๊ฟ  น้ำ  ที่สุด  เสื้อ  ป้า  ปิ่น  ฟ้า  (ส่วนนี้ไม่ต้องสแกน)
