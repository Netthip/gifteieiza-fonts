# Gifteieiza Blend — ฟอนต์ลายมือกิฟ ตัวที่ดีที่สุดจาก 4 สไตล์ ⭐

รวมตัวที่ดีที่สุดของแต่ละตัวอักษรจาก 4 สไตล์แม่แบบมินิ (Round / Slim / Firm / Soft)
แล้วปรับให้เข้ากันเป็นลายมือชุดเดียว: เส้นหนาเท่ากันทุกตัว, หัวพยัญชนะสูงเท่ากัน, เส้นฐานตรงกัน, ความกว้างสมดุล

![ตัวอย่าง](specimen.png)

## เลือกตัวไหนมาจากไหน

| สไตล์ต้นทาง | ตัวที่ใช้ | เหตุผล |
|---|---|---|
| **Soft** (แกนหลัก) | พยัญชนะส่วนใหญ่, ะ า ำ เ แ โ ใ ไ, เลขไทย, เลข 0–9 | หัวกลมเปิดชัด เส้นสม่ำเสมอที่สุด |
| Round | ก จ ฉ ฆ ฌ ณ ฐ ๒ และ " ' # % - @ \ _ | ตัวสวยสมดุลกว่า / ของ Soft หัวทึบ |
| Firm | ฎ ฏ ฒ ล ส ห + สระบน วรรณยุกต์ สระล่างทั้งชุด | สะอาดที่สุด (ตัวอื่นหัวเป็นก้อน) — ขยายขนาดให้เท่าค่ากลาง |
| Slim | อ ฮ ฯ ๆ + ตัวอังกฤษ A–Z a–z ทั้งชุด และ ! ? | ขนาดพอดี / Soft ไม่มีตัวเล็กอังกฤษ, f ของ Round เหมือน t |

การปรับ: Firm แคบลง ×0.86 (ตัวกว้าง), Slim กว้างขึ้น ×1.07 (ตัวแคบ), สระ/วรรณยุกต์ของ Firm ขยาย ×1.11,
ทุกตัวหนาเส้น 47 หน่วย (ค่ากลางของ 4 สไตล์) โดยวาดใหม่ตามแกนกลางเส้นลายมือเดิม

ตรวจแล้ว: สระ–วรรณยุกต์ไม่ชนตัวอักษร 2,438/2,438 แบบ · Word ใช้ฟอนต์นี้ครบทั้งไทยและอังกฤษ
